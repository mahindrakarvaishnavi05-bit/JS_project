# Task Manager App

A simple and responsive Task Manager Web Application developed using HTML, CSS, and JavaScript. This application helps users organize daily activities, manage tasks, and track their progress.

## Features

- Add new tasks with a title and description.
- Set task priority (Low, Medium, High).
- Set due dates for tasks.
- Edit existing tasks.
- Mark tasks as completed or pending.
- Delete tasks.
- Search tasks by title or description.
- Filter tasks by All, Pending, and Completed.
- View total, pending, and completed task statistics.
- Automatically save tasks using Browser Local Storage.
- Responsive design for desktop and mobile devices.

## Technologies Used

- **HTML5** – Structure of the application.
- **CSS3** – Styling and responsive design.
- **JavaScript** – Application functionality and task management.
- **Local Storage** – Saving tasks in the browser.

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `code.html` in your web browser.
4. Alternatively, use the Live Server extension in VS Code.

## How to Use

1. Enter a task title.
2. Add an optional task description.
3. Select the task priority.
4. Choose a due date if required.
5. Click the **Add Task** button.
6. Use the Edit, Complete, and Delete buttons to manage tasks.
7. Use the search bar and filters to find specific tasks.

## Data Storage

The application uses the browser's Local Storage to save tasks. Tasks remain available after refreshing the browser on the same browser and device, unless the stored data is cleared.
